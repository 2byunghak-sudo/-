# 🏐 스파이크온! (SpikeOn!) - 중학교 체육 배구 수업 마스터 웹앱

중학교 체육 교사와 학생들을 위해 제작된 **반응형 스마트 배구 학습 & 수업 지원 웹 애플리케이션**입니다.
외부 유료 API 호출 없이 순수 웹 표준(React, TypeScript, Tailwind CSS, Web Audio API)으로 작동하며, Vercel 및 GitHub, Google Project IDX 배포에 최적화되어 있습니다.

---

## 🌟 주요 기능 및 교육과정 연계

1. **배구 기초 이론 & 8대 핵심 규칙**
   - 18m × 9m 정규 코트 규격 대화형 SVG 뷰어
   - 중학교 남학생(2.30m) / 여학생(2.15m) 네트 높이 비교
   - 8대 규칙(3단 연결, 더블 콘택트, 네트터치, 오버넷, 캐치/홀딩, 인/아웃, 풋폴트, 로테이션) 카드 & 교사 실전 꿀팁
   - 1~6번 포지션 및 리베로 역할 심층 해설

2. **4대 기본 기능 마스터 가이드**
   - 언더핸드 패스, 오버핸드 패스/토스, 서브(언더/오버), 스파이크 & 블로킹
   - 4단계 동작 순서 & 순간 점검 기준
   - 중학생 빈출 실수 & 즉각 교정 처방
   - 인터랙티브 자가진단 체크리스트 & 공 타구음 시뮬레이션

3. **인터랙티브 전술 보드 & 로테이션 시뮬레이터**
   - 9m × 9m 배구 코트 위 선수 말 터치 & 드래그 자유 배치
   - **[시계방향 로테이션]** 버튼 클릭 시 1~6번 자리 시계방향 이동 및 현재 서브 선수 강조
   - 추천 포메이션 프리셋 (W형 5인 리시브, U형 리시브, 레프트 오픈 공격 커버)
   - 전술 펜/지우개 드로잉 툴 내장 (태블릿/빔프로젝터 판서 지원)

4. **형성평가 퀴즈 (배구 마스터 자가진단)**
   - 10문항(OX 및 4지선다형) 퀴즈와 즉각적인 효과음 및 해설
   - 점수에 따른 칭호 부여 & 축하 꽃가루(Confetti) 효과
   - 틀린 문제만 모아보는 오답 집중 복습 노트

5. **나의 배구 배움일지 (수행평가 포트폴리오)**
   - 학번, 성명, 집중 기술, 연속 성공 횟수(+1/+5 카운터), 자기평가 별점, 성찰 기록
   - **LocalStorage 자동 보관** 및 **Firebase Firestore 실시간 클라우드 자동 동기화**
   - 선생님 제출용 인쇄 및 PDF 저장 지원

6. **실전 경기 스코어보드 & 심판 도우미**
   - A팀 vs B팀 점수판 및 세트 스코어 집계
   - 서브권 자동 표시 및 24:24 듀스(Deuce) 판정
   - 30초 작전타임 카운트다운 타이머 & 휘슬 호각 사운드
   - 심판 수신호(인, 아웃, 터치아웃, 네트터치 등) 가이드

## 🚀 배포 가이드 (Vercel / GitHub / Project IDX)

### 1. Vercel 원클릭 무료 배포 (권장)
1. GitHub에 본 저장소 코드를 푸시합니다.
2. [Vercel](https://vercel.com)에 로그인 후 **Add New Project**를 클릭합니다.
3. 해당 GitHub 저장소를 선택하면 Framework Preset이 `Vite`로 자동 인식됩니다.
4. 별도 빌드 설정 변경 없이 **Deploy**를 클릭하면 1분 이내에 무료 HTTPS 웹 주소가 발급됩니다.

### 2. 로컬 개발 및 실행
```bash
# 1. 패키지 설치
npm install

# 2. 로컬 개발 서버 실행 (포트 3000)
npm run dev

# 3. 프로덕션 빌드 테스트
npm run build
```

## ☁️ Firebase 실시간 데이터 연동 안내 (선택 사항)

앱 상단의 **[저장소 설정]** 버튼을 눌러 Firebase 설정을 1초 만에 완료할 수 있습니다:
1. [Firebase Console](https://console.firebase.google.com)에서 무료 프로젝트 생성
2. Firestore Database 생성 (테스트 모드)
3. 웹 앱(`</>`) 등록 후 생성된 `firebaseConfig` 객체를 복사하여 앱 내 설정 모달창에 붙여넣기만 하면 실시간 동기화가 시작됩니다.
*(Firebase를 설정하지 않아도 브라우저 LocalStorage를 통해 학생들의 데이터가 기기에 100% 안전하게 저장됩니다.)*
